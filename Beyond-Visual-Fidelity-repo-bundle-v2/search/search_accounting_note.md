# Search-accounting note

The retained project record does not contain a complete native-database export and global deduplication trail from Scopus, Web of Science, ACM Digital Library, and IEEE Xplore.

Accordingly:
- public-web `site:` searches are not represented as native database searches;
- unsupported conventional PRISMA identification counts are not reconstructed;
- corpus-wide prevalence claims are bounded to the assessed evidence base;
- late discoveries are handled through a dated update log.

This limitation is disclosed in the manuscript.
