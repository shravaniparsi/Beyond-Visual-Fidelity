# Evidence-derived reporting framework

This framework is a synthesis product; it has not been independently validated as a standard.

| Domain | Minimum reporting elements |
|---|---|
| Claim & task scope | Construct; input evidence; output framework; generation/edit/repair mode; human/tool intervention |
| Instrument & role | Formula/implementation/version; reference; thresholds; learned-judge prompt/model; aggregation; role |
| Population & denominator | Attempted N; failures; exclusions; retries; selected/evaluable N; observation unit |
| Validation & reliability | Criterion; sample; estimator; uncertainty; rater protocol; tuning versus confirmation |
| Environment & direct tests | Browser/runtime/viewport/assets/timing; action/assertion or wider-condition tests when claimed |
| Dependence & reproducibility | Benchmark lineage; shared samples/raters; artifacts; hashes/commits; historical-run equivalence; inference limit |
